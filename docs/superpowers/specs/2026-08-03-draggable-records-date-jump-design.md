# 流水页“跳转日期”按钮自由拖拽设计

## 背景与目标

流水页的“跳转日期”按钮目前使用固定的右侧与底部偏移。用户希望可自由移动该按钮，并在刷新页面或再次进入流水页后恢复上次位置。

本次目标：

- 触屏、鼠标和触控笔均可直接拖动按钮。
- 拖动后停留在用户释放的位置，不自动吸附左右边缘。
- 轻点按钮仍正常打开“跳转日期”选择器，拖动结束不误触发打开。
- 用户实际拖动后保存位置；刷新或再次进入流水页时恢复。
- 屏幕尺寸或方向变化后自动把按钮限制在安全可视区域内。
- 保持当前首次进入时的默认位置、图标、尺寸和视觉样式。

## 交互规则

按钮按下后记录指针起点。指针移动距离超过 6px 才进入拖拽状态；未超过阈值时按普通点击处理。拖拽期间按钮跟随指针移动，并使用指针捕获保证手指或鼠标短暂离开按钮后仍能连续移动。

释放指针时：

- 若发生拖拽，保留释放位置、保存偏好，并抑制紧随其后的合成点击事件。
- 若未发生拖拽，继续调用 `ModernDateField` 提供的 `open` 方法。
- 若收到 `pointercancel`，恢复到本次拖拽开始前的位置，不写入偏好。

按钮不强制吸边。拖拽范围保留 12px 视口边距，底部边界优先取当前可见底部导航栏顶部再上移 12px；底部导航不可见时使用视口底部安全边界。页面内容滚动不改变按钮位置。

## 状态与持久化

在 `frontend/src/utils/floatingPosition.ts` 中定义无环境依赖的位置比例类型和归一化函数，并由 `frontend/src/utils/preferences.ts` 的统一偏好对象增加可选字段：

```ts
interface FloatingPositionPreference {
  xRatio: number
  yRatio: number
}
```

`recordsJumpFabPosition` 保存按钮左上角在当前安全可用区域内的横纵比例，范围均为 `0` 到 `1`。使用比例而不是绝对像素，使同一位置在不同屏幕尺寸和方向下保持相近的相对位置。

新增读取与保存函数：

```ts
loadRecordsJumpFabPosition(): FloatingPositionPreference | undefined
saveRecordsJumpFabPosition(value: FloatingPositionPreference): FloatingPositionPreference
```

偏好模块复用 `normalizeFloatingPosition()`，读取时仅接受有限数值并限制到 `[0, 1]`；非法或缺失值回退为未保存状态。未保存时沿用现有默认位置：日卡片模式位于底部导航上方，时间线模式继续为“返回顶部”按钮预留初始空间。只有用户实际完成拖拽后才保存位置；一旦保存，切换查看模式不再覆盖用户选择的位置。

## 页面实现

拖拽行为保留在 `RecordsView.vue`，不抽取通用组件，因为当前只有一个浮动控件需要自由拖拽，避免引入未被其他页面需要的抽象。

页面维护：

- 按钮元素引用、当前像素坐标和是否已有用户位置。
- 指针起点、拖拽起点、当前指针 ID、是否越过阈值及是否抑制下一次点击。
- 根据视口、按钮尺寸和底部导航位置计算的安全边界。

使用 Pointer Events 统一处理 `pointerdown`、`pointermove`、`pointerup`、`pointercancel`。拖拽样式通过固定定位的 `left` 与 `top` 更新，并清除原先动态 `bottom`；首次默认位置仍由现有视图模式规则计算。窗口 `resize` 时重新根据已保存比例或当前坐标进行限制，并在组件卸载时移除监听。

按钮继续保留 `aria-label="跳转日期"` 与 `title="跳转日期"`。拖拽区域设置 `touch-action: none` 和 `user-select: none`，拖动时使用 `grabbing` 光标，非拖动时使用 `grab` 光标。

## 异常与冲突处理

- `localStorage` 数据损坏或字段非法时忽略保存位置，使用当前默认位置。
- 底部导航暂时不存在或隐藏时，以视口边界作为回退。
- 安全区域小于按钮尺寸时，优先保证按钮左上角可见并禁止产生负坐标。
- 拖拽仅从按钮自身开始，不接管流水卡片横滑、记录左滑或页面纵向滚动。
- “返回顶部”按钮保持原行为和位置；首次默认布局仍不重叠，用户自由拖动后不对其位置做自动吸附或强制改写。

## 测试与验证

1. 为位置比例归一化和非法值回退增加 Node 回归测试；保存/读取通过真实页面刷新回归覆盖。
2. 使用真实 Chromium 在 430 × 932 视口打开流水页，拖动按钮后断言按钮跟随指针、位于安全边界内，且日期选择器没有误打开。
3. 重新加载页面，断言按钮恢复到保存后的相对位置。
4. 轻点未拖动的按钮，断言“跳转日期”选择器正常打开。
5. 将按钮拖向四个边界，确认坐标被限制且不会遮住底部导航。
6. 运行 `npm run check:ui`、新增浏览器回归和 `npm run build`。
