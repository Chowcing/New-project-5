# 日期时间选择器数字输入设计

## 背景与目标

全站日期与日期时间入口统一复用 `frontend/src/components/ModernDateField.vue`。当前 `datetime` 模式通过小时、分钟双列滚轮选择时间，但逐项滚动在需要精确跳转到较远数值时效率较低。

本次调整在保留现有滚轮交互的基础上，为小时和分钟增加直接数字输入能力。用户点击滚轮中当前选中的小时或分钟后，可编辑对应数值；日期、月份、年份模式不受影响。

## 交互设计

- 小时、分钟滚轮继续作为默认时间选择方式。
- 只有点击某列当前选中的值时，才打开该列的紧凑数字输入弹窗；点击其他滚轮项仍沿用 Vant Picker 的滚动选择行为。
- 小时和分钟分别编辑，弹窗标题与字段标签明确显示当前编辑对象。
- 输入框使用数字键盘，并在打开后自动聚焦、选中原值，便于直接覆盖。
- 小时接受 `0` 至 `23`，分钟接受 `0` 至 `59`。允许输入一位或两位数字，确认后统一格式化为两位数。
- 输入为空、含非数字字符或超出范围时，不关闭弹窗，不改变滚轮值，并显示对应有效范围提示。
- 点击取消或关闭输入弹窗时，不改变原时间。
- 输入确认成功后，更新临时时间并同步滚轮选中项；日期时间底部面板保持打开，用户仍需点击主面板的“确定”才写回表单。

## 组件与数据流

改动限定在 `ModernDateField.vue` 的 `datetime` 分支：

1. 为小时、分钟列的选中项提供可点击入口。
2. 组件内部记录正在编辑的列、草稿文本和校验错误。
3. 打开编辑弹窗时，从 `tempTime` 读取对应值。
4. 编辑确认通过后，将格式化值写回 `tempTime`；现有 `confirm()` 继续负责把日期和时间组合为最终 `modelValue`。
5. `chooseToday()`、重新打开日期选择器以及滚轮更新仍以 `tempTime` 为单一临时时间来源，因此数字输入与现有交互保持双向一致。

数字输入弹窗复用项目统一的 `BottomSheet`，不直接新增 `van-popup`。输入控件实际字号不低于 16px，并提供清晰的小时或分钟标签、取消和确定按钮。

## 边界与错误处理

- 不自动截断越界值，避免把误输入静默改成另一时间。
- 输入确认前不修改 `tempTime`，保证取消操作可完整回退。
- 打开或关闭主日期时间面板时，清理数字输入草稿和错误状态，避免状态串到下一次编辑。
- 保持主面板取消语义：即使已经用数字输入更新了临时时间，只要取消主面板，表单原值仍不变。

## 测试与验收

在现有 `frontend/tests/modern-date-field-ui.mjs` 浏览器回归中覆盖：

- 点击小时选中项打开小时数字输入，原值被带入。
- 输入合法小时后滚轮同步到两位数结果。
- 点击分钟选中项并输入合法分钟后滚轮同步。
- 小时或分钟越界时显示提示、弹窗保持打开且滚轮值不变。
- 取消数字输入不修改临时时间。
- 数字输入更新临时时间后，取消主日期时间面板仍保留表单原值。
- 最终确认主面板后，表单显示完整的用户格式日期时间。
- `date`、`month`、`year` 模式不出现时间数字输入入口。

完成后运行 `npm run test:modern-date-field`、`npm run check:ui` 和 `npm run build`，并在移动端视口确认输入弹窗、数字键盘入口和原时间滚轮均可正常使用。
